# Under Glass — Grok

A closed terrarium studio. Place plants, stone, and small life in a glass, then set the soil, mist, and light. The line under the glass says whether the mix will keep.

No install step. Serve this folder and open it.

```bash
python3 -m http.server 8000 --directory Grok
```

Open http://localhost:8000.

## What you can do

- Four vessels: globe, jar, bowl, and cloche.
- Eighteen pieces: ferns, figs, succulents, moss, mushrooms, stone, wood, a snail, a frog, and a beetle.
- Drag a piece sideways. Select it to scale, flip, restack, or remove it.
- Ground controls for pebbles, soil, charcoal, a moss carpet, mist, and dawn, day, or dusk light.
- A short care note when the planting wants two different climates.
- Shuffle, undo, and redo. Save keeps the glass in this browser only.
- Starters: Quiet fern, Dry bowl, Moss ward, and Palm house.

Arrow keys nudge the selected piece. Shift moves it further. Delete or Backspace removes it. Ctrl or Cmd+Z undoes. Ctrl or Cmd+Shift+Z redoes.

Artwork is original studio cutouts made for this build. Designs stay on this device. Nothing is sent to a server.
